                     TERMINAL QUIZ-GAME
You will build a quiz app capable of:
-Reading questions from a file

-Asking them in random order

-Accepting and checking answers

-Tracking the score and streaks

-Saving high scores persistently

This project involves file parsing, randomization, loops, user input handling, state management, and simple data storage—all essential scripting skills.

    FEATURES

-Randomized Questions
Questions are loaded from a questions.txt file and shuffled before being shown.

-Scoring System
Every correct answer increases your score. Incorrect answers reset your current streak.

-Streak Tracking
The game monitors:

Current streak

Longest streak achieved in the session
